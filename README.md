# Financial Performance Dashboard – Power BI & Excel

## Overview
This project features an interactive Financial Performance Dashboard built using **Microsoft Power BI** and **Excel**. It provides a comprehensive analysis of financial performance, evaluating overall revenue, profitability, cost structures, and Budget vs. Actual variance across multiple customer segments and product lines.

## Analytical Insights & Visualizations
The report transforms raw financial data into strategic insights through interactive visual components:

- **Budget vs. Actual Variance Analysis:** Identifies under- and over-performing business sectors using segment-specific targets.
- **Profit Margin Trend:** Line chart comparing Total Sales and Profit Margin % across Year, Quarter, Month, and Day.
- **Segment Performance:** Bar charts analyzing Total Profit and Budget Variance % across 5 segments (*Government, Small Business, Channel Partners, Midmarket, Enterprise*).
- **Product Profitability:** Detailed breakdowns of Total Sales and Total Profit across 6 products (*Paseo, VTT, Velo, Amarilla, Montana, Carretera*).
- **Discount Band Distribution:** Donut charts illustrating sales distribution by discount category (*Medium, High, Low, None*).
- **Financial Matrix Tables:** Detailed cross-analysis tables mapping total profit by product across market segments.
